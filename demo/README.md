Interactive demo for [depthpro-mlx](https://github.com/ntoantoan/depthpro-mlx): Apple's Depth Pro, ported to MLX, estimates metric depth from one photo; each scene is a self-contained WebGL viewer (drag to look around, **Depth**, **Measure**).

Photos: Wikimedia Commons contributors, see [CREDITS.md](CREDITS.md). Depth Pro by Apple; not affiliated with Apple.
